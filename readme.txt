
Description:
This project is “I Am Toast," a prototype game based off of I Am Bread. Beginner project made without the use of a game engine.
Users play as a slice of bread with the goal of becoming toast, having to avoid obstacles along the way. 
These obstacles can lower their edibility bar, and if this bar reaches 0, the game is over. 
Once the player reaches a toaster and becomes toast, the game ends with a score based off of the remaining edibility bar.

To run the project:
Run the main.py file.

Libraries:
None

Shortcuts:
You can press "r" at any point to reset to the start of the level.
